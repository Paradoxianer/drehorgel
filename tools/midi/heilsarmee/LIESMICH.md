# MIDI-Dateien für die Heilsarmee-Rolle

Hier die MIDI-Dateien (`.mid`) ablegen, aus denen die neue Notenrolle entsteht.
`tools/drehorgel_audio.py` liest sie ein und baut daraus Rolle, Index und mp3.

Bitte nur Lieder, die gemeinfrei sind oder für die eine Erlaubnis vorliegt –
das gilt für Melodie, Text-Titel **und** das MIDI-Arrangement selbst.
